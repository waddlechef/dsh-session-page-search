一个 DeepSeek Harness 的会话内页面查找插件：在当前页面里像浏览器一样查找文字，实时统计命中数量，高亮全部匹配并在匹配项之间跳转，不修改页面 DOM。查找栏浮在会话正文上方，跟随窗口和侧栏变化，亮/暗主题自动适配。

![查找栏预览](docs/preview.svg)

## 功能

- `Ctrl+F`（macOS 为 `Cmd+F`）打开查找栏，也可以点击编辑器工具行里的放大镜按钮。
- 输入即搜，显示 `当前/总数`，没有匹配时显示「无结果」。
- `Enter` / `↓` 跳到下一个，`Shift+Enter` / `↑` 跳到上一个，首尾循环。
- `Aa` 区分大小写，`ab` 全词匹配，两个开关都按浏览器 profile 记忆。
- `Esc`、关闭按钮都可以收起查找栏，焦点离开查找栏后 `Esc` 仍然有效。
- 关闭时把搜索期间滚动过的容器恢复到打开查找栏时的位置，不会把页面留在某个匹配处。
- 页面在流式输出、工具卡片展开、切换会话时自动重扫，计数与高亮保持最新。
- 查找栏居中在会话正文列上方，跟随窗口尺寸、侧栏和右侧面板变化。
- 高亮使用主题色，亮色和暗色主题下都能看清，匹配控制可以自由组合。
- 浏览器标签页里没有额外快捷键，用编辑器工具行的放大镜按钮打开（`Ctrl+F` 留给浏览器原生查找）。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开 / 聚焦查找栏 | `Ctrl+F` / `Cmd+F` |
| 下一个 / 上一个匹配 | `Enter` / `Shift+Enter`（或 `↓` / `↑`） |
| 关闭查找栏 | `Esc` |
| 浏览器标签页打开 | 点击编辑器工具行的放大镜按钮（浏览器保留 `Ctrl+F` 做原生查找） |

命令也会出现在 设置 → 通用 → 键盘快捷键 里（名称「在当前页面中查找」），可以重新绑定。

## 安装

插件是纯 JavaScript 编写、无第三方依赖、无构建步骤，要求 DSH 0.2 以上。

### 桌面端

打开 设置 → 插件，填入地址 `github:waddlechef/dsh-session-page-search`。

安装后通常立即生效。如果界面里还没有查找栏，重启 DSH 后按 `Ctrl+R` 刷新页面。

### 网页端

执行以下命令。

```bash
dsh plugin --profile <profile> add github:waddlechef/dsh-session-page-search
```

## 卸载

### 桌面端

在 设置 → 插件 里移除。

### 网页端

执行以下命令。

```bash
dsh plugin --profile <profile> remove dsh-session-page-search
```

## 使用

安装后无需任何额外配置。

按 `Ctrl+F` 打开查找栏，直接输入要查找的文字。查找栏会自动聚焦输入框并全选上次的查询词，继续输入即可替换。

- 所有匹配项用选区色高亮，当前匹配项用强调色高亮。
- 查找范围是当前页面**已渲染**的内容：会话正文、工具输出、侧栏和弹窗都会搜索。隐藏元素和折叠未渲染的内容不在范围内，需要先展开。
- 单次扫描最多 2000 条匹配，达到上限时计数后面显示 `+`。
- 在 设置 → 通用 → 键盘快捷键 里可以把命令改绑到其他按键。

## 实现说明

- 通过 `shell.overlay` 插槽挂载浮动查找栏，样式使用宿主主题 token，边框与阴影沿用输入框卡的 `--dsw-elevation-soft` 与 `--dsw-alias-border-l2` 描边，跟随亮/暗主题。
- 高亮使用 CSS Custom Highlight API（`CSS.highlights` + `::highlight()`），不包裹、不修改页面 DOM，不影响 React 渲染。不支持该 API 时仍可计数和跳转，只是不绘制高亮。
- 页面变化通过 `MutationObserver` 增量重扫，查找栏自身的 DOM 变动会被忽略。
- 打开查找栏时对会话滚动容器做一次位置快照，关闭时恢复。
- 快捷键通过宿主 shortcuts 服务注册，同时保留一个捕获阶段的 `Ctrl/Cmd+F` 兜底，桌面端原生分发可用时该兜底处于休眠状态。

## 目录结构

| 文件 | 作用 |
| --- | --- |
| `client.js` | 查找栏、搜索与高亮、滚动恢复、编辑器触发按钮、命令注册 |
| `index.js` | 惰性 Host 半边（能力在浏览器侧） |

| `locale/en.json`、`locale/zh.json` | 插件管理器的标题与描述 |
| `icon.svg` | 插件图标 |
| `docs/preview.svg` | README 预览图 |

## 开发

纯 JavaScript，无构建步骤。修改 `client.js` 后，Client 半边会通过 HMR 自动重载，不需要重启应用。

```bash
node --check client.js
```
